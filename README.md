A modern, elegant, and minimal personal portfolio website crafted for **Siddhi Rameshwar Nanaware**, Computer Engineering student at Dr. D. Y. Patil College of Engineering & Innovation, Pune.

- **Hero & Identity Section**: Features Siddhi's professionally cropped executive portrait (blazer & tie), headline, key metrics (8.7 CGPA, 2nd Year B.E.), and direct CTAs.

- **Contact & Communication**: Working interactive contact form, 1-click email copy button with toast feedback, and direct links to LinkedIn & GitHub.

## 💻 Local Development

To run this project locally:

```bash
# 1. Navigate to the project directory
cd siddhi-portfolio

# 2. Install dependencies (if not already installed)
npm install

# 3. Start development server
npm run dev

# 4. Build for production
npm run build

# 5. Preview production build locally
npm run preview
```

## 🚀 How to Deploy to Vercel & GitHub

### Step 1: Initialize Git Repository

```bash
cd siddhi-portfolio
git init
git add .
git commit -m "Initial commit: Siddhi Nanaware Portfolio"
```

### Step 2: Push to GitHub

1. Create a new public repository on GitHub named `siddhi-portfolio` (at `https://github.com/new`).
2. Run the following commands in your terminal:

```bash
git branch -M main
git remote add origin https://github.com/siddhinanaware/siddhi-portfolio.git
git push -u origin main
```

### Step 3: Deploy to Vercel (Instant 1-Click)

1. Go to [https://vercel.com](https://vercel.com) and log in with your GitHub account.
2. Click **"Add New..."** → **"Project"**.
3. Select your `siddhi-portfolio` repository.
4. Framework Preset will automatically detect **Vite**.
5. Click **"Deploy"**.
6. Within 30 seconds, Vercel will give you a live HTTPS link (e.g. `https://siddhi-portfolio.vercel.app`) that you can submit in college forms and display on LinkedIn!
